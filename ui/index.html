      Setup

      Switch on up to 4 microphones. Each one gets its own push-to-talk key and its own channel in the multitrack file. A mic's own button works if it sends a key — press it when choosing the key.

      Keep before each pressAudio kept from just before the key goes down, so the first word is never cut.
      Keep after releaseThe mic stays open this long after the key is released, so the last word isn't clipped.

      Each recording creates a folder <case>_<date>_<time> with _mix.wav (all mics mixed), _multitrack.wav (one channel per mic) and _info.json (who spoke when).

      Open from other software: PathoSync.exe --case S26-1234 --folder "D:\Recordings" --exit-after-save
